# Home-Manager Configuration

Currently, no custom options are declared.

## List of Modules

- [`default`](./default.nix): Entrypoint for importing all modules and some miscellaneous config.
  Also declares some core options such as home directory, user name, and catppuccin theme.
- [`editors`](./editors.nix): Configures code editors, lsps, formatters, and related software.
- [`gtk`](./gtk.nix): GTK configuration.
- [`programs`](./programs.nix): Miscellaneous programs configurations.
- [`services`](./services.nix): Configures home-manager services.
- [`spotify`](./spotify.nix): Configures everything related to spotify.
- [`swaylock`](./swaylock.nix): Swaylock config.
- [`terminals`](./terminals.nix): Configures terminals, shells, CLI programs, and related software.
- [`wm`](./wm.nix): Configures window managers, compositors, and related software such as bars and launchers.
